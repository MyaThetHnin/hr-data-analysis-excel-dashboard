# HR Employee Analytics Dashboard | Excel

## Overview

This project is an interactive HR Analytics Dashboard built entirely in Microsoft Excel. The dashboard analyzes employee data to provide insights into workforce demographics, employee attrition, job satisfaction, and overall HR metrics.

## Dataset

**Source:** Kaggle – HR Employee Dataset

The dataset contains transaction-level sales data, including:

The dataset contains employee information such as:

- Employee demographics
- Department
- Job Role
- Education
- Age
- Gender
- Marital Status
- Salary
- Attrition
- Job Satisfaction
- Years at Company

## Data Preparation

Before building the dashboard, the dataset was cleaned and prepared by:

- Removing duplicate records
- Removing unnecessary columns
- Creating Age Groups for easier analysis
- Checking for missing or inconsistent values
- Preparing the data for Pivot Tables

## Dashboard Features

The dashboard includes:

### Pivot Tables

Five Pivot Tables were created to summarize HR data, including:

- Employee distribution by Department
- Attrition by Department
- Employees by Age Group
- Average Scores by Department
- Employee Hiring Trends

### Charts

The dashboard includes interactive charts such as:

- Employee Distribution
- Hiring Trends
- Age Group Breakdown
- Average Scores by Department

### KPI Cards

- Total Employees
- Average Engagement
- Average Work-Life Balance
- Average Satisfaction

### Interactive Filters

Slicers allow users to filter the dashboard by:
- Department
- Year
